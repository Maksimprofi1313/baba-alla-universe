# Baba Alla Universe

Коллекция Python-проектов: игры, небольшие настольные утилиты и эксперименты с локальной сетью.

## Структура

- `games/` — текстовые игры и шуточные симуляторы из вселенной Бабы Аллы.
- `utilities/` — калькулятор, «Матрица», генератор паролей, менеджер задач и универсальный конвертер.
- `network-lab/` — инструменты диагностики локальной сети и экспериментальные сетевые примеры.

## Запуск

Нужен Python 3.10+ (рекомендуется актуальная версия Python 3).

Большинство файлов запускаются отдельно:

```bash
python "games/Текстовый квест про Бабу Аллу.py"
```

Для GUI-программ нужен Tkinter. Дополнительные библиотеки перечислены в `requirements.txt`.

## Важно о network-lab

Сетевые скрипты оставлены как учебные эксперименты и диагностические примеры. Используй их только в собственной сети или в лаборатории, где у тебя есть явное разрешение. Не направляй сканирование на чужие устройства и не пытайся перехватывать или подменять чужой трафик. Генерируемые тестовые сертификаты не следует устанавливать как доверенные для обычного использования.

## Сохранность

Перемещение файлов по папкам не меняет их содержимое. История Git сохраняет предыдущую версию расположения.
