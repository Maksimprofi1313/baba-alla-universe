# Baba Alla Universe

Коллекция Python-проектов: игры, небольшие настольные утилиты и эксперименты с локальной сетью.

## Структура

- `games/` — текстовые игры и шуточные симуляторы из вселенной Бабы Аллы.
- `utilities/` — калькулятор, «Матрица», генератор паролей, менеджер задач и универсальный конвертер.
- `network-lab/` — инструменты диагностики локальной сети и учебные примеры.

## Требования и запуск

- Python 3.10 или новее.
- Для графических программ нужен Tkinter (обычно входит в установщик Python для Windows).
- Внешние Python-библиотеки устанавливаются командой:

```bash
python -m pip install -r requirements.txt
```

Быстрый запуск игрового меню из корня репозитория:

```bash
python games/launcher.py
```

Лаунчер автоматически находит все Python-игры в папке `games/` и запускает выбранную отдельным процессом. Новые игры появятся в меню автоматически.

Отдельные программы можно запускать напрямую:

```bash
python "games/Текстовый квест про Бабу Аллу.py"
python utilities/password_generator.py
python network-lab/site_checker.py
```

Каждый скрипт запускается отдельно. Большинство игр и простых утилит используют только стандартную библиотеку Python.

## Состав разделов

### games

Семь консольных игр и шуточных симуляторов. Некоторые сценарии намеренно абсурдны и не являются инструкциями к реальным действиям.

### utilities

- `password_generator.py` — генератор паролей на базе `secrets`.
- `task_manager.py` — GUI-менеджер задач; локальные данные хранятся в `utilities/tasks.json`.
- `universal_converter.py` — конвертер валют и криптовалют; для актуальных котировок требуется интернет и доступность внешних API.
- `калькулятор.py` — консольный калькулятор.
- `матрица.py` — консольная анимация.

### network-lab

- `site_checker.py` — проверка TCP-доступности выбранных сайтов.
- `network_scanner.py` — чтение локальной ARP-таблицы.
- `Сканер Wi-Fi сетей.py` — просмотр доступных Wi-Fi сетей через Windows `netsh`.
- `network_map.py` — графическая карта устройств; использует системные `ping` и `arp`.
- `Сканер портов.py` — проверяет ограниченный список портов только на loopback, частных и link-local IP.
- `mock_server.py` — локальный Flask-сервер, привязанный только к `127.0.0.1:5000`; заголовки запросов не записываются.
- `generate_certs.py` — создаёт тестовый самоподписанный сертификат и приватный ключ.
- `dns_spoof.py` — офлайн-демонстрация разбора имени DNS-запроса; сетевой перехват и подмена ответов отключены.

Запускай сетевые диагностические инструменты только для собственных устройств и сетей, либо при наличии явного разрешения. Результаты сканирования не всегда точны: например, отсутствие ответа на ping не доказывает, что устройство выключено.

## Безопасность и локальные файлы

- Не устанавливай тестовые сертификаты как доверенные для обычного использования.
- Файлы `server.key` и `server.crt`, а также `utilities/tasks.json` исключены из Git через `.gitignore`.
- Не добавляй приватные ключи, пароли, токены или персональные данные в репозиторий.

## Проверка синтаксиса

Локальная проверка всех исходников:

```bash
python -m compileall -q games utilities network-lab
```
